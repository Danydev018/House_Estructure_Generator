# 🚀 Configuración de Supabase para House Structure Generator

Este documento te guía paso a paso para configurar Supabase y conectar tu proyecto de Godot con la base de datos y el almacenamiento de archivos.

## 📋 Prerrequisitos

1. ✅ Proyecto de Godot funcionando
2. ✅ Scripts de Supabase ya integrados en tu proyecto
3. ✅ Conexión a internet

## 🏗️ Paso 1: Crear Proyecto en Supabase

### 1.1 Crear Cuenta
1. Ve a [https://supabase.com](https://supabase.com)
2. Crea una cuenta gratuita
3. Verifica tu email

### 1.2 Crear Nuevo Proyecto
1. Click en "New Project"
2. Elige tu organización
3. Llena los datos:
   - **Name**: `house-generator`
   - **Database Password**: Genera una contraseña segura (guárdala)
   - **Region**: Elige la más cercana a tu ubicación
4. Click "Create new project"
5. ⏱️ Espera 2-3 minutos mientras se crea el proyecto

## 🗃️ Paso 2: Configurar la Base de Datos

### 2.1 Crear la Tabla `space`
1. Ve a la sección **SQL Editor** en el panel izquierdo.
2. Click en **New query**.
3. Copia y pega el siguiente código SQL:

```sql
-- Crear tabla para guardar las rutas a los archivos de escena
CREATE TABLE public.space (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    name text NULL,
    route text NULL,
    CONSTRAINT space_pkey PRIMARY KEY (id)
);

-- Habilitar Row Level Security (opcional pero recomendado)
ALTER TABLE public.space ENABLE ROW LEVEL SECURITY;

-- Permitir acceso público de lectura
CREATE POLICY "Enable read access for all users" ON "public"."space"
AS PERMISSIVE FOR SELECT
TO public
USING (true);

-- Permitir inserción para usuarios anónimos (los que usan la anon_key)
CREATE POLICY "Enable insert for anon users" ON "public"."space"
AS PERMISSIVE FOR INSERT
TO anon
WITH CHECK (true);
```

4. Click **Run** para ejecutar el código.
5. ✅ Deberías ver "Success. No rows returned".

## 📦 Paso 3: Configurar el Almacenamiento (Storage)

### 3.1 Crear un Bucket
1. Ve a la sección **Storage** en el panel izquierdo.
2. Click en **New Bucket**.
3. Ingresa el nombre del bucket: `scenes`.
4. Asegúrate de que la opción **Public bucket** esté **marcada (activada)**. Esto es crucial para que el juego pueda descargar los archivos de escena.
5. Click en **Create Bucket**.

### 3.2 Configurar Políticas del Bucket (Si no lo hiciste público)
Si no marcaste el bucket como público, puedes hacerlo manualmente con políticas de acceso.
1. Ve a **Storage** -> **Policies**.
2. Busca el bucket `scenes` y haz click en **New Policy**.
3. Elige la plantilla **"Enable read access to public"** para permitir que cualquiera pueda leer los archivos.
4. Para permitir que tu juego suba archivos, crea otra política con esta configuración:
   - **Policy Name**: `Allow anon uploads`
   - **Allowed operations**: Marca `insert`.
   - **Target roles**: Marca `anon`.
   - **Policy definition**:
     ```sql
     (bucket_id = 'scenes'::text)
     ```
5. Click en **Review** y luego en **Save**.

## 🔑 Paso 4: Obtener Credenciales

### 4.1 Obtener URL y API Key
1. Ve a **Settings** → **API**.
2. Copia estos valores:
   - **Project URL**: `https://tu-proyecto-id.supabase.co`
   - **anon/public Key**: La clave larga que empieza con `eyJ...`

## ⚙️ Paso 5: Configurar tu Proyecto de Godot

### 5.1 Actualizar SupabaseManager.gd
1. Abre `Scripts/SupabaseManager.gd`.
2. Reemplaza las líneas de `SUPABASE_URL` y `SUPABASE_ANON_KEY` con tus valores reales de Supabase.

```gdscript
const SUPABASE_URL = "https://tu-proyecto-id.supabase.co"
const SUPABASE_ANON_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

### 5.2 Verificar Nodos en la Escena Principal
1. Abre tu escena `Main.tscn`.
2. Asegúrate de que los nodos `SupabaseManager` y `SceneStateManager` existan y tengan sus scripts asignados correctamente.

## 🧪 Paso 6: Probar la Nueva Configuración

1. Ejecuta tu proyecto de Godot (F5).
2. Crea o mueve algunos bloques en la escena.
3. Presiona el botón de **Guardar**.
4. Revisa la consola de Godot. Deberías ver logs como:
   ```
   💾 Iniciando nuevo flujo de guardado...
   ⬆️ Subiendo archivo: scene_1672531200.json
   ⬆️ Respuesta de subida - Código: 200
   ✅ Archivo subido exitosamente: ...
   ✍️ Insertando registro en la tabla 'space'...
   ✍️ Respuesta de inserción en DB - Código: 201
   ✅ Registro en 'space' creado exitosamente
   ```
5. **Verifica en Supabase**:
   - Ve a **Storage** -> **scenes**. Deberías ver el nuevo archivo `.json`.
   - Ve a **Table Editor** -> **space**. Deberías ver una nueva fila con el `name` y la `route` del archivo.
6. Reinicia el proyecto de Godot. La escena debería cargarse automáticamente al estado que guardaste.

¡Listo! Tu proyecto ahora guarda las escenas como archivos en Supabase Storage y mantiene un registro en la base de datos. 🏠☁️
