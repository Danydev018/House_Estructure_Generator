# 🏠 House Structure Generator

Una herramienta innovadora de construcción 3D basada en bloques, desarrollada con **Godot Engine 3.x**, pensada para agentes inmobiliarios y usuarios particulares que deseen visualizar y modelar estructuras arquitectónicas de forma intuitiva y multiplataforma.

---

## 📋 Descripción del Proyecto

**House Structure Generator** permite:

### 🏢 Agentes Inmobiliarios Profesionales
- Crear maquetas digitales de propiedades
- Presentar diseños de interiores a clientes
- Visualizar modificaciones estructurales en tiempo real

### 🏡 Usuarios Particulares
- Modelar la estructura de su hogar deseado
- Experimentar con diferentes distribuciones de espacios
- Agregar muebles y elementos decorativos
- Visualizar el diseño interior futuro

---

## ✨ Características Principales

- 🎮 Navegación en primera persona (mouse + teclado)
- 📱 Soporte multiplataforma: PC y Android
- 🧱 Sistema de bloques: creación, selección, escalado y rotación
- 🎯 Interfaz táctil optimizada para móviles
- 🔄 Manipulación en tiempo real con retroalimentación visual

---

## 🛠️ Requisitos del Sistema

### 💻 PC
- OS: Windows 7/10/11, macOS 10.12+, Linux Ubuntu 16.04+
- Godot Engine: 3.x
- RAM: 2GB mínimo
- GPU: Compatible con OpenGL ES 2.0

### 📱 Android
- Android 4.4+ (API level 19)
- RAM: 1GB mínimo
- Almacenamiento: 100MB libres
